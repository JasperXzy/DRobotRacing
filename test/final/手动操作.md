# 实时观察人工调整时的小车地图位置和方向

先正常开启定位相关终端，再单独开启一个终端运行：

```bash
source /root/D_Robot/test/dev_ws/install/setup.bash
ros2 run tf2_ros tf2_echo map base_link
```

终端会持续输出：

- `Translation [x, y, z]`：`base_link` 中心在 `map` 中的位置，划人工调整区时记录 `x/y` 的最小值和最大值。
- `Rotation in RPY (radian) [roll, pitch, yaw]`：小车姿态，平面方向主要观察 `yaw`。
- `Rotation in RPY (degree)`：同一姿态的角度值，更方便直接观察车头方向。

移动和旋转小车时保持该指令运行；观察结束后按 `Ctrl+C`。最终人工调整区应在实测 `x/y` 范围外再留少量余量。
