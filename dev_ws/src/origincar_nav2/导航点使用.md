# origincar_nav2 Python 节点使用指南

> 路径：`src/origincar_nav2/origincar_nav2/`

---

## 节点总览

| 节点 | 文件 | 用途 | 阶段 |
|------|------|------|:---:|
| waypoint_recorder | `waypoint_recorder.py` | 在 RViz 地图上点击录制路径点 | 录制 |
| waypoint_cruiser | `waypoint_cruiser.py` | 按路径点自动巡航，Nav2 自主规划+避障 | 运行 |
| map_overlay_publisher | `map_overlay_publisher.py` | 将图片叠加到 RViz 3D 地图上 | 可视化 |

### 数据流

```
waypoint_recorder（录制）
    ↓ 生成 waypoints.yaml
waypoint_cruiser（巡航）
    → 调用 Nav2 navigate_to_pose → 自主导航

map_overlay_publisher（独立）
    → /map_overlay/image + /map_overlay/marker
```

---

## 1. waypoint_recorder — 路径点录制器

### 作用

监听 RViz 的 `/clicked_point` 话题，在地图上点哪里就记录哪里的 (x, y, yaw) 坐标，Ctrl+C 后自动保存为 YAML 文件。

### 使用步骤

```bash
# 1. 先启动导航 + RViz
ros2 launch origincar_nav2 origincar_nav2.launch.py

# 2. 启动录制器
ros2 run origincar_nav2 waypoint_recorder

# 或指定输出路径
ros2 run origincar_nav2 waypoint_recorder \
  --ros-args -p output_file:=/home/user/my_waypoints.yaml
```

### RViz 操作

1. 顶部工具栏点击 📍 **"Publish Point"** 图标
2. 在地图上依次点击想要车经过的位置
3. 每点一次，终端打印 `✅ #N: (x, y, yaw=0.0)`
4. 按 **Ctrl+C** 结束 → 自动保存

### 参数

| 参数 | 默认值 | 作用 |
|------|--------|------|
| `output_file` | `./recorded_waypoints.yaml` | 输出 YAML 文件路径 |

### 监听话题

| 话题 | 类型 | 说明 |
|------|------|------|
| `/clicked_point` | `geometry_msgs/PointStamped` | RViz Publish Point 工具发布 |

## 2. waypoint_cruiser — 自动巡航节点

### 作用

按顺序读取路径点列表，逐个发送 `navigate_to_pose` 动作目标给 Nav2，让车子自主规划路径并避障行驶。支持循环和单次两种模式。

### 使用步骤

```bash
# 基础用法（内置默认路径点，无限循环）
ros2 run origincar_nav2 waypoint_cruiser

# 指定路径点文件（推荐配合 waypoint_recorder 使用）
ros2 run origincar_nav2 waypoint_cruiser \
  --ros-args -p waypoints_file:=~/D_Robot/dev_ws/src/origincar_nav2/origincar_nav2/waypoints.yaml

# 单次模式（跑完所有点就停）
ros2 run origincar_nav2 waypoint_cruiser \
  --ros-args -p cruise_mode:=once

# 调整到达容忍距离（默认 0.5m）
ros2 run origincar_nav2 waypoint_cruiser \
  --ros-args -p waypoint_tolerance:=0.3
```

### 参数

| 参数 | 默认值 | 作用 |
|------|--------|------|
| `cruise_mode` | `loop` | `loop`=无限循环巡航，`once`=跑完停止 |
| `waypoint_tolerance` | 0.5 | 到达目标点的容忍距离 (m) |
| `waypoints_file` | 空（用内置） | YAML 路径点文件路径 |

### YAML 路径点格式

```yaml
waypoints:
  - [x1, y1, yaw1]
  - [x2, y2, yaw2]
  - [x3, y3, yaw3]
```

### 工作流程

```
1. 发布 initialpose（初始位姿设为原点）
2. 等待 Nav2 navigate_to_pose 动作服务器就绪
3. 逐个发送路径点目标
4. 每个目标到达后 → 等 1 秒 → 发下一个
5. 最后一个到达后：
   - loop 模式：回到第1个继续
   - once 模式：结束退出
```

### 依赖的 Nav2 动作

| 动作 | 说明 |
|------|------|
| `/navigate_to_pose` | Nav2 的导航动作服务器 |

## 3. map_overlay_publisher — 地图图片叠加

### 作用

将一张 PNG/JPG 图片以两种方式叠加到 RViz 上：
1. **Image 话题** → RViz Image 面板中显示
2. **Marker 地面纹理** → RViz 3D 视图中平铺，支持透明度调节

### 使用步骤

```bash
# 基础用法（自动用包里的 map/my_map.png）
ros2 run origincar_nav2 map_overlay_publisher

# 指定自定义图片
ros2 run origincar_nav2 map_overlay_publisher \
  --ros-args -p image_file:=/path/to/image.png

# 调节透明度和原点位置
ros2 run origincar_nav2 map_overlay_publisher \
  --ros-args -p alpha:=0.8 -p origin_x:=0.0 -p origin_y:=0.0
```

### 参数

| 参数 | 默认值 | 作用 |
|------|--------|------|
| `image_file` | `map/my_map.png`（包内路径） | 图片文件路径 |
| `resolution` | 0.025 | 像素对应实际尺寸 (m/pixel) |
| `origin_x` | -0.68 | 图片左下角在 map 坐标系中的 X |
| `origin_y` | -6.48 | 图片左下角在 map 坐标系中的 Y |
| `alpha` | 0.6 | 透明度 0~1（1=不透明） |
| `publish_image` | true | 是否发布 `/map_overlay/image`（Image 面板） |
| `publish_marker` | true | 是否发布 `/map_overlay/marker`（3D 地面纹理） |

### 发布的话题

| 话题 | 类型 | 用途 |
|------|------|------|
| `/map_overlay/image` | `sensor_msgs/Image` | RViz Image 面板中显示 |
| `/map_overlay/marker` | `visualization_msgs/Marker` | RViz 3D 视图地面叠加 |

### RViz 配置

在 RViz 中添加：
- **By topic** → `/map_overlay/image` → 选择 Image 显示类型
- **By topic** → `/map_overlay/marker` → 选择 Marker 显示类型

## 完整工作流示例

```bash
# ===== 第一步：录制路径点 =====
ros2 launch origincar_nav2 origincar_nav2.launch.py    # 终端1
ros2 run origincar_nav2 waypoint_recorder              # 终端2
# → 在 RViz 中点击路径点 → Ctrl+C 保存

# ===== 第二步：启动自动巡航 =====
ros2 run origincar_nav2 waypoint_cruiser \
  --ros-args -p waypoints_file:=./recorded_waypoints.yaml

# ===== 可选：叠加图片装饰 =====
ros2 run origincar_nav2 map_overlay_publisher
```
