# 阿克曼小车适配方案（全局 Planner + 局部 Controller）

## 概要
适配到阿克曼小车的场景，分两层给出可执行建议：
- 全局层（Planner）：确保生成的路径满足车辆运动学约束（含朝向、最小转弯半径、是否允许倒车）。
- 局部层（Controller）：修改跟随控制器以仅输出阿克曼可执行量（`linear.x` + `angular.z`），并实现“航向优先”策略以避免 90° 卡死。

目标：保证路径可走、控制可执行、减少因横向 `linear.y` 导致的卡死或抖动。

## 关键原则
- Planner 和 Controller 都必须理解车辆约束（状态应包含 `x,y,theta`）。
- 局部控制禁止直接使用 `linear.y` 横移修正；把横向误差映射为航向修正或短暂倒退。
- 保持安全值与饱和处理：最小速度、角速度限幅、紧急停止阈值等。

## 全局层（Planner） 推荐

- 推荐算法/实现：
  - Hybrid A*（状态空间包含 `theta`，适合考虑朝向）
  - State Lattice / Smac Lattice / Smac Hybrid（Nav2 可选实现）
  - Reeds-Shepp（允许倒车）或 Dubins（仅前进）作为局部段拼接备选

- Nav2 推荐：使用 `smac_planner`（smac_hybrid 或 smac_lattice），并设置：
  - 车辆几何：`footprint`, `wheel_base`（轴距 L），`min_turn_radius` 或 `min_turning_radius`
  - `allow_reverse`: true（若允许倒车）
  - 输出轨迹带朝向信息（pose with theta）

- 注意：planner 生成的路径需要与 local controller 的跟踪周期与期望格式一致（例如路径密度/时间间隔）。

## 局部层（Controller） 具体改造（阿克曼专用）

1. 禁止 `linear.y`：任何来自 `lidar_tracker` 的横向命令都应被忽略或映射。
2. 航向优先策略（伪代码）：

```
angle_err = atan2(target_y, target_x)
dist = sqrt(target_x^2 + target_y^2)
ANGLE_THRESHOLD = 30_deg (≈0.52 rad)
if |angle_err| > ANGLE_THRESHOLD:
    // 先调整朝向，减小前进速度
    cmd.linear.x = sign(dist) * slow_speed (或 0)
    cmd.angular.z = clamp(angle_err * k_ang, -w_max, w_max)
else:
    // 朝向小则正常跟随
    cmd.linear.x = clamp((dist - FOLLOW_DIST) * k_lin, -v_max, v_max)
    cmd.angular.z = clamp(angle_err * k_ang, -w_max, w_max)
```

3. 低速保护：当 `|v| < v_eps` 时，不用公式直接算 AngleR（避免数值不稳）；优先用角度差控制转向。
4. 倒车规则：当目标位于车辆后侧且角度接近 180° 时，可允许短时倒车配合转向（前提：planner 允许倒车）。
5. 势场(Repulse) 处理：若目前使用 APF，将横向排斥力 `repulse_y` 在阿克曼模式下映射为 `angular.z` 修正，而非 `linear.y`。
6. 死区与最小速度：设置 `min_speed`、`angle_deadzone` 避免低速抖动。
